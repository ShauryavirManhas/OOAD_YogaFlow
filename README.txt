YogaFlow interactive prototype 2.0 (Sprint 2)

Open index.html in a modern browser. No server or installation is required.

Use the "Preview as" selector to switch between Studio Manager, Studio Staff,
Instructor (Maya Chen), and Customer (Alex Morgan). Data is sample data kept
in this browser. Use "Reset sample data" in the sidebar to start over.

Suggested demonstration path:
1. Instructor: Class check-in, Alex Morgan. The pass that expires first is
   chosen automatically. Confirm, then Submit roster (it locks).
2. Staff: Class check-in, Priya Shah. Her payment is pending; tick the
   override, give a reason, and confirm.
3. Staff: Passes & purchases, Jordan Lee (412-555-0102). The senior discount
   is applied automatically from the date of birth.
4. Manager: Manage schedule, Create class on the same evening as Vinyasa
   Flow. The room and instructor conflicts are listed.
5. Manager: Reports. Sales report and Attendance & utilization.

Files: index.html (shell), styles.css (design), domain.js (business rules and
controllers, mirrors the class diagrams in Report 2.0), app.js (screens).

This is a front-end prototype. It does not charge cards or connect to the
studio's systems. Prices and the senior discount rate are sample values.
